# Legacy Roleplay

Рабочий код RAGE:MP: `packages/server` — сервер, `client_packages` — интерфейсы и клиентские скрипты.

## Совместная работа

1. Клонируйте этот закрытый репозиторий. Доступ выдаёт владелец GitHub.
2. Перед работой: `git pull --ff-only`.
3. После правок сделайте commit и push (можно через GitHub Desktop).
4. На ПК владельца изменения автоматически получаются в `D:\LegacyRoleplay`, только если нет локальных незакоммиченных правок.

Для сохранения через PowerShell: `./tools/Save-Changes.ps1 -Message "Описание изменения"`.
Для разового получения: `./tools/Sync-Project.ps1 -Once`.
При конфликте автосинхронизация останавливается; правки не удаляются.

## Файлы окружения

Пароли, SSH-ключи, база игроков, логи, исполняемые файлы RAGE и DLC не входят в Git.
Настройки базы задаются через переменные из `.env.example`. Сервер использует переменные окружения; загрузку локального `.env` настраивайте в своём запуске.
Папка `client_packages/game_resources` с DLC передаётся отдельно.
Исполняемый сервер устанавливайте из официального RAGE:MP.

## Сервер

После Push в main GitHub Actions проверяет код и публикует успешную версию в deploy-ready. VPS получает её раз в минуту: проверяет код повторно, создаёт резервную копию и перезапускает игру при изменениях игровых файлов. Неудачный запуск возвращает предыдущие файлы. Подробности: [ops/autodeploy/README.md](ops/autodeploy/README.md).
Не сохраняйте в репозиторий production-дампы базы и пароли.
