# Автоматическая установка на VPS

## Для разработчиков

1. Работайте в main: Commit и Push.
2. Дождитесь зелёной проверки [GitHub Actions](https://github.com/talipovtimur347-cpu/legacy-roleplay/actions).
3. Успешный актуальный коммит публикуется в служебную ветку deploy-ready.
4. VPS проверяет её примерно раз в минуту. Устанавливаются packages/server и client_packages, кроме приватных и больших игровых ресурсов.
5. При изменении игровых файлов сервер кратко перезапускается. Документация и инструменты перезапуска не требуют.

Не редактируйте deploy-ready вручную. Если проверка красная, исправьте ошибку и отправьте новый коммит.
Пароли, база игроков, конфигурация подключения, SSH-ключи, node_modules и DLC сохраняются отдельно. Новые npm-зависимости и DLC устанавливает владелец VPS.

## Защита данных

Перед заменой файлов сохраняются изменяемые прежние файлы и SQL-копия базы. Успешный запуск требует готовности RAGE, MySQL и старой админ-системы.
При неудаче автоматически возвращаются файлы предыдущей версии. Содержимое базы автоматически не откатывается, чтобы не терять прогресс игроков; SQL-копия предназначена для ручного восстановления владельцем.
Неудачный коммит не устанавливается повторно каждую минуту. Новый коммит запускает новую проверку.
Если игровые файлы изменены напрямую на VPS, автоустановка останавливается: сначала перенесите эти правки в Git.
Хранятся последние пять резервных копий установок. Изменения только CRLF/LF не перезапускают сервер и не заставляют повторно скачивать ресурсы.

## Управление владельцем VPS

Агент /opt/legacy-autodeploy/deploy.py и его systemd-службы принадлежат root. Их новые версии из Git не устанавливаются автоматически: изменения инфраструктуры требуют отдельного просмотра.
GitHub-ключ на VPS имеет право только читать этот репозиторий. В GitHub не сохранены SSH-пароли или приватный ключ входа на VPS.

Статус: `cat /var/lib/legacy-autodeploy/status.json`.
Журнал: `journalctl -u legacy-autodeploy.service -n 60 --no-pager`.
Таймер: `systemctl status legacy-autodeploy.timer`.
Остановить автоустановку: `systemctl disable --now legacy-autodeploy.timer`.
Проверить без установки: `python3 /opt/legacy-autodeploy/deploy.py --dry-run`.
Повторить отклонённую версию вручную: `python3 /opt/legacy-autodeploy/deploy.py --retry`.
Резервные копии: /srv/ragemp-updates/legacy-autodeploy.
